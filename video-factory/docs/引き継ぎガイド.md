# 引き継ぎガイド（新しい PC に移るとき）

## 考え方

「**GitHub にあるもの ＋ 手で作り直す少しの秘密 ＝ 全部**」になるようにしています。
PC が壊れても、GitHub と下の「秘密のメモ」さえあれば元に戻せます。

## GitHub に保存するもの

- プログラム（`scripts/`）とデザイン（`templates/`）
- 環境構築スクリプト（`setup/`）… 何をどのバージョンで入れるかの記録も兼ねる
- バージョン指定ファイル（`.node-version` = Node.js 22、`.python-version` = Python 3.12）
- 小さい元データ（`data/`）、使ってよい素材（`assets/`）
- 設定の見本（`.env.example`）

## GitHub に保存してはいけないもの（`.gitignore` で自動的に除外）

| もの | 理由 | 新しい PC ではどうする？ |
|---|---|---|
| `.env`（APIキー等） | 盗まれると悪用される | パスワード管理アプリに控えておき、手で作り直す |
| YouTube 認証ファイル（`client_secret*.json` など） | 同上 | Google Cloud から再ダウンロード |
| `output/` の動画・音声 | 大きすぎる・作り直せる | 必要ならスクリプトで再生成。残したい完成品は YouTube / 外付けドライブへ |
| `node_modules/`、`.venv/` | 自動で作り直せる | セットアップ手順で自動生成 |
| 他人の著作物（買った BGM・有料フォント等） | 公開リポジトリだと再配布になる | 購入元から再ダウンロード |

> 注意: このリポジトリは **公開（誰でも見られる）** 状態です。秘密は絶対に入れないでください。

## 引き継ぎの手順（Mac を買ったら）

1. 古い PC で、最後の作業を GitHub に保存（Claude に「GitHub に保存して」と頼めばOK）
2. 秘密のメモ（`.env` の中身）をパスワード管理アプリなどに控える
3. 新しい Mac で README の「Mac での手順」を実行
4. GitHub からプロジェクトを取ってくる（Claude が手順を案内します）
5. `.env.example` をコピーして `.env` を作り、控えておいた値を書く
6. 動作テスト（Claude に「テスト動画を作って」と頼む）
